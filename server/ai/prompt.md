【特殊交易处理规则 (非常重要)】

1. **退款 (Refund)**:

   - 如果截图/文本包含 "退款", "退货", "Refund"：
   - **Assets (资产)** 记为 **正数 (+)** (钱回来了)。
   - **Expenses (支出)** 记为 **负数 (-)** (冲销之前的消费)。
   - Example: Assets:Cash:Alipay 99.00 CNY, Expenses:Shopping:Clothing -99.00 CNY

2. **返现 (Cashback)**:

   - 如果截图/文本包含 "好评返现", "返现", "返红包", "商家补贴"：
   - 本质是这笔消费的事后折价，**与退款同样处理**：资金账户 (Assets 或 Liabilities) 记为 **正数 (+)**，**原消费对应的支出账户**记为 **负数 (-)**。
   - 支出分类跟着**原消费**走 (外卖好评返现 -> `Expenses:Food:Delivery`)，**禁止**记成 `Income`——那会让原消费的支出永远留在统计里，支出和收入同时虚高。
   - 钱返到哪个账户就记哪个，不必与原消费的付款账户相同 (常见:原单走信用卡，返现进微信零钱)。
   - **例外**: 与具体消费无关的奖励 (拉新奖励、签到红包、刷卡达标返现) 无原分类可冲减，记 `Income:Rewards`
     (平台/银行给的权益返还; `Income:Gift` 是**人**给的钱，别混)。`Income:Other` 是兜底，
     只在**确实判断不出来源**时才用——把认得出的东西塞进兜底桶，就没法再靠它发现识别错误。

3. **还款 (Repayment)**:
   - 如果包含 "信用卡还款", "还白条", "还花呗"：
   - 这不是消费，是债务偿还。
   - 如果文本暗示有额外费用(如"手续费", "利息"), 请拆分为 3 行: 负债(本金+), 费用(支出+), 资产(总额-)。
   - 如果有**积分/权益抵扣** (现金实付**少于**消债金额), 差额记 `Income:Rewards` **负数 (-)**——
     方向与手续费相反。**禁止**冲减任何 `Expenses`: 还款不是消费，没有原分类可冲。
   - **Liabilities (负债)** 记为 **正数 (+)** (债务减少)。
   - **Assets (资产)** 记为 **负数 (-)** (钱出去了)。
